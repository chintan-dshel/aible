Running in Production

This section covers what's different about deploying AI systems compared to conventional software: non-determinism, confidence without calibration, silent failures, and the unique challenges of monitoring something that outputs free text.

Reading order — taking a system to production​

  1. Reliability — circuit breakers, retries, backoff
  2. Graceful Degradation — fallback hierarchy
  3. Monitoring — LLM-as-judge, structural metrics, alerts
  4. Deployment Patterns — shadow mode, canary, A/B
  5. Confidence Estimation — when to trust the model
  6. Fallbacks — multi-model fallback chains

Supplement with Observability, Evals, and Output Validation in Infrastructure and Tooling.

Topics​

  • Reliability — retry logic, idempotency, circuit breakers for LLM calls
  • Graceful Degradation — fallback content, confidence thresholds, human escalation
  • Confidence Estimation — logprobs, self-consistency, calibration
  • Fallbacks — model fallback chains and deterministic fallback content
  • Monitoring — drift detection, quality regression, alerting
  • Deployment Patterns — shadow mode, A/B, canary, blue-green for AI systems

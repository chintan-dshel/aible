Start Here

A personal AI reference — built to be the resource I wanted when learning this field: technically honest, practically grounded, and honest about what isn't settled. Each page follows the same structure: what it is, how it works, working code, when to use it, failure modes, and where to go deeper.

Reading paths​

"I'm new to AI and want to understand how it actually works"​

Start with Foundations, read in order:

  1. What is AI? — situates ML in the broader landscape
  2. How LLMs Work — the high-level picture before the details
  3. Neural Networks — the underlying mechanism
  4. Transformers — the architecture everything is built on
  5. Attention — the key idea that makes transformers work
  6. Embeddings — how meaning becomes geometry
  7. Tokenization — how text becomes numbers
  8. Training vs. Inference — what happens before and after deployment

The history pages (Timeline, Narrative) are optional — good context, not mechanistic prerequisites.

"I'm a developer building with AI APIs right now"​

You probably don't need the full Foundations section. Start with:

  1. Prompting — system prompts, few-shot, chain-of-thought
  2. Structured Outputs — reliable JSON extraction
  3. Function Calling — tools, parallel calls, execution loops
  4. RAG — retrieval-augmented generation end to end
  5. Evals — how to know if your system is working
  6. Guardrails — input/output safety
  7. Prompt Injection — the attack surface you most need to understand

Then pick from Meta-Infrastructure based on what you're building:

  • Caching heavy workloads → Caching + Latency Optimization
  • Managing costs → Model Routing + Cost Tracking
  • Complex pipelines → Orchestration Frameworks + MCP
  • Document-heavy workloads → Document Processing + Vector Databases

"I'm taking a system to production"​

Go straight to Production Concerns, then work backward to whatever foundations are needed:

  1. Reliability — circuit breakers, retries, backoff
  2. Graceful Degradation — fallback hierarchy
  3. Monitoring — LLM-as-judge, structural metrics, alerts
  4. Deployment Patterns — shadow mode, canary, A/B
  5. Confidence Estimation — when to trust the model
  6. Fallbacks — multi-model fallback chains

Supplement with: Observability, Evals, Output Validation.

"I'm building multi-agent systems"​

  1. Multi-Agent Systems — topologies, trust, coordination
  2. Memory Architectures — in-context, external, parametric
  3. Function Calling — the tool layer
  4. Access Control for Agents — least-privilege, permission scoping
  5. Prompt Injection — the key attack surface in agentic systems
  6. Long-Horizon Agents — planning, checkpointing, human-in-the-loop gates
  7. Agentic Computer Use — GUI automation, screenshot-act loops

"I want to understand where AI is heading"​

The Aspirational section covers what's emerging or not yet production-ready. Confidence levels are lower by design — the field hasn't settled on answers, and each page says so explicitly.

Start anywhere. Suggested order if you want a coherent narrative:

  1. Long-Horizon Agents — the hardest near-term problem
  2. Agentic Computer Use — GUI control as the general interface
  3. World Models — the debate about what LLMs actually understand
  4. Multimodal Frontier — where vision, audio, and text meet
  5. On-Device AI — privacy and the quantization inflection point
  6. Novel Interaction Paradigms — voice, ambient, spatial
  7. AI Safety Research — alignment, interpretability, the control problem

"I only have 30 minutes"​

Read these four pages:

  • How LLMs Work — the mental model everything else builds on
  • Prompting — the highest-leverage practical skill
  • RAG — how to ground models in your own data
  • Evals — the thing most teams skip and most wish they hadn't
